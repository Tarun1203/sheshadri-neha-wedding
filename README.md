# Sheshadri & Neha — Wedding Invitation

Interactive wedding invitation website · 12 & 13 December 2026 · Gokul Function Hall

## Pages
1. Opening — envelope with kalasha seal
2. Main — names, date, arch photo frame
3. Invitation & couple
4. Save the date — calendar + countdown
5. Events — Reception (12 Dec), Muhurtham (13 Dec)
6. Gallery
7. Venue — directions
8. Thank you

Backgrounds switch automatically between portrait (phones, upright tablets) and landscape (desktop, sideways screens).

## Adding photos
Put images in `img/` and set the paths in the `PHOTOS` object near the top of the `<script>` in `index.html`.
